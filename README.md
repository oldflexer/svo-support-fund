# Благотворительный фонд «Защитим Родину»

Веб-платформа для поддержки участников СВО. Проект включает публичный сайт с информацией о сборах, новостях и возможностью пожертвований, а также полноценную админ-панель для управления контентом и пользователями.

## ✨ Возможности

### 🌍 Публичная часть
- Отображение текущих сборов с фильтрацией по статусу и прогресс-барами
- Лента новостей/отчётов/историй с фильтрацией по категориям
- Форма пожертвований (анонимно или с именем, привязка к сбору)
- Форма заявки волонтёра
- Статистика (сумма собранных средств, количество волонтёров)
- Учредительные документы (PDF)

### ⚙️ Админ-панель (доступна по `/admin`)
- Дашборд с графиком пожертвований и последними операциями
- Детальная статистика по всем сущностям
- CRUD для сборов, новостей (с поддержкой множественных изображений)
- Управление статусами пожертвований и заявок волонтёров
- Управление администраторами/модераторами (роли admin/moderator)
- Журнал действий (аудит) с фильтрацией
- Системные настройки (реквизиты, соцсети, включение модулей)
- Двухфакторная аутентификация (2FA) для администраторов
- Уведомления о новых пожертвованиях и заявках (polling)

## 🛠️ Технологический стек

- **Backend**: Python 3.10+, Flask, SQLAlchemy, JWT, PyOTP, Alembic
- **Frontend**: Vue 3 (модульная структура), Vite, Chart.js, CSS (адаптивный дизайн)
- **База данных**: SQLite (может быть заменена на PostgreSQL)
- **Дополнительно**: Werkzeug, WTForms, qrcode, Pillow

## 📡 API Endpoints (основные)

### Публичные
- `GET /api/public/stats` – общая статистика
- `GET /api/public/drives` – список сборов (с фильтрацией)
- `GET /api/public/news` – список новостей (только verified)
- `GET /api/public/news/<slug>` – детальная информация о новости
- `POST /api/public/donations` – создание пожертвования
- `POST /api/public/volunteers` – заявка волонтёра

### Административные (требуют JWT)
- `GET /api/admin/dashboard` – данные для дашборда
- `GET /api/admin/stats` – детальная статистика
- CRUD для `donations`, `drives`, `news`, `volunteers`, `users`, `audit`, `settings`
- `POST /api/admin/upload` – загрузка изображений

### Аутентификация
- `POST /api/auth/login` – вход (с поддержкой 2FA)
- `POST /api/auth/refresh` – обновление токена
- `GET /api/auth/me` – информация о текущем пользователе
- `POST /api/auth/logout` – выход
- Эндпоинты для управления 2FA (`setup`, `enable`, `disable`, `backup-codes`)
