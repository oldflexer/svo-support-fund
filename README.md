# Благотворительный фонд «Защитим Родину»

Веб-платформа для поддержки участников СВО. Проект включает публичный сайт с информацией о сборах, новостях и возможностью пожертвований, а также полноценную админ-панель для управления контентом и пользователями.

## ✨ Возможности

### 🌍 Публичная часть

  - 📦 Отображение текущих сборов (с фильтрацией по статусу)
  - 📰 Лента новостей и отчётов (с фильтрацией по категориям)
  - 💸 Форма пожертвований (анонимно или с указанием имени)
  - 🤝 Форма заявки волонтёра
  - 📊 Статистика (сумма собранных средств, количество волонтёров)
  - 📄 Учредительные документы (PDF)

### ⚙️ Админ-панель (доступна по `/admin`)

  - 📈 Дашборд с графиком пожертвований и последними операциями
  - 📉 Детальная статистика по пожертвованиям, сборам, новостям, волонтёрам
  - 🔧 CRUD для сборов, новостей, пользователей (администраторов/модераторов)
  - 🔄 Управление статусами пожертвований и заявок волонтёров
  - 📋 Журнал действий (аудит)
  - 🛠️ Настройки сайта (реквизиты, соцсети, включение модулей)
  - 🔐 Двухфакторная аутентификация (2FA) для администраторов

## 🛠️ Технологический стек

  - **Backend**: Python 3.10+, Flask, SQLAlchemy, JWT, PyOTP (2FA)
  - **Frontend**: Vue 3 (CDN), Chart.js, CSS (адаптивный дизайн)
  - **База данных**: SQLite (может быть заменена на PostgreSQL)
  - **Дополнительно**: Werkzeug, WTForms, qrcode, Pillow

## Предварительные требования

📡 API Endpoints  

🌐 Публичные  
GET /api/public/stats – общая статистика  
GET /api/public/drives?status=&page=&per_page= – список сборов  
GET /api/public/news?category=&page=&per_page= – новости  
POST /api/public/donations – создание пожертвования  
POST /api/public/volunteers – заявка волонтёра  

🔒 Административные (требуют JWT)  
GET /api/admin/dashboard – данные для дашборда  
GET /api/admin/stats – детальная статистика  
CRUD для donations, drives, news, volunteers, users, audit, settings
